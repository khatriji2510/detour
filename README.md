# VOIDWEAR Clean

A simplified Next.js 14 + TypeScript + Tailwind CSS streetwear site with:
- App Router
- Home and Shop pages
- Hero carousel
- Category sidebar filtering
- Product cards
- Dark premium styling
- Next/font/google fonts
- Vercel-friendly config

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
